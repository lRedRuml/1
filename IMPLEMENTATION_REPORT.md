### ✅ 1. Удаление заглушек из кода

#### Проблема #1: Hardcoded сервер в ConnectScreen
**Было:** Экран подключения отображал жестко кодированное имя сервера `"Германия · Frankfurt"` вместо того, чтобы показывать динамический выбранный сервер.

**Файл:** `app/lib/screens/connect_screen.dart`

**Что исправлено:**
- ✅ Добавлен импорт `SelectedServer` (состояние выбранного сервера)
- ✅ Добавлен listener на изменения выбранного сервера (`_onServerSelected`)
- ✅ Реализована функция `_getCountryCode()` для динамического извлечения кода страны из имени сервера
- ✅ Заменен hardcoded ServerPill на динамический:
  - Раньше: `code: 'DE', name: 'Германия · Frankfurt'`
  - Теперь: `code: serverCountryCode, name: selectedServerName` (получаются из SelectedServer.displayName)

**Как это работает:**
```dart
// При открытии экрана подключения
final selectedServerName = SelectedServer.displayName.value ?? 'Сервер';
final serverCountryCode = _getCountryCode(selectedServerName);

// Функция извлекает первое слово (обычно код страны) из имени сервера
String _getCountryCode(String? name) {
  if (name == null || name.isEmpty) return '??';
  final firstWord = name.trim().split(RegExp(r'\s+')).first;
  return firstWord.length >= 2 ? firstWord.substring(0, 2).toUpperCase() : firstWord.toUpperCase();
}
```

**Результат:** Теперь экран подключения показывает правильный выбранный сервер, а не жестко кодированный значение. При выборе другого сервера на экране "Серверы" — значение сразу обновляется.

## 🚀 Шаги для запуска на своем сервере

1. **Подготовить backend:**
   - Скопировать файлы из `backend-patch/` на сервер
   - Добавить переменные в `.env` (API_KEY, GMAIL_PASSWORD)
   - Выполнить `set_payment_settings.py`
   - Перезапустить бота

2. **Подготовить 3x-ui панели:**
   - Убедиться, что панели доступны по HTTPS
   - Добавить записи в таблицу `xui_hosts` БД бота

3. **Собрать приложение:**
   ```bash
   cd app
   flutter pub get
   flutter build apk --release
   ```
   или использовать GitHub Actions workflow "Build Android APK"

4. **Протестировать:**
   - Установить APK на тестовый телефон
   - Пройти регистрацию
   - Купить пробный тариф
   - Подключиться к VPN
   - Проверить, что интернет работает

## ❓ Часто задаваемые вопросы

**Q: Почему приложение не подключается?**
A: Сначала проверьте, правильно ли настроен backend (следуйте разделу "Backend настройка" в `VPN_SERVER_CONNECTION_GUIDE.md`). Затем используйте раздел "Диагностика проблем" для поиска конкретной ошибки.

**Q: Как изменить API ключ?**
A: Сгенерируйте новый ключ, замените его в `.env` бота и в `defaultValue` в `app/lib/main.dart`, затем пересоберите приложение.

**Q: Как добавить новый VPN сервер?**
A: Добавьте запись в таблицу `xui_hosts` БД бота с параметрами 3x-ui панели. Новый сервер автоматически появится в приложении.

**Q: Почему трафик показывает 0 MB?**
A: Это может быть проблема с платформенной настройкой (iOS/macOS нужна Network Extension) или сервер не маршрутизирует трафик. См. раздел "Трафик не передаётся" в диагностике.
