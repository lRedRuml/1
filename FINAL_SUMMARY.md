## 📌 Что было сделано

### 1. ✅ Удалена основная заглушка кода

**Проблема:** Экран подключения (ConnectScreen) показывал hardcoded значение `"Германия · Frankfurt"` вместо реально выбранного сервера.

**Решение реализовано в файле:** `app/lib/screens/connect_screen.dart`

**Конкретные изменения:**
```dart
// БЫЛО (hardcoded):
ServerPill(
  code: 'DE',
  name: 'Германия · Frankfurt',  // ← жёстко захардкодировано!
  ...
)

// СТАЛО (динамическое):
final selectedServerName = SelectedServer.displayName.value ?? 'Сервер';
final serverCountryCode = _getCountryCode(selectedServerName);

ServerPill(
  code: serverCountryCode,  // ← получается динамически
  name: selectedServerName,  // ← получается динамически
  ...
)
```

**Как это работает:**
1. При открытии экрана подключения читается значение `SelectedServer.displayName`
2. Добавлен listener, который срабатывает при изменении выбранного сервера
3. Страна автоматически извлекается из имени сервера (первые 2 буквы)
4. UI обновляется автоматически без перезагрузки экрана

**Результат:**
- ✅ Экран "Подключение" теперь показывает правильный сервер
- ✅ При смене сервера на экране "Серверы" значение сразу обновляется
- ✅ Нет больше несоответствий между выбором и отображением

## 🎯 Пошаговая инструкция для запуска

### Шаг 1: Подготовить backend (на сервере)
```bash
# Скопировать файлы
cp backend-patch/api.py /path/to/shopbot/src/shop_bot/webhook_server/
cp backend-patch/database.py /path/to/shopbot/src/shop_bot/webhook_server/

# Обновить .env (ключи берутся из backend-patch/ENV_ADDITIONS.env)
# Выполнить скрипт платежей
python3 backend-patch/set_payment_settings.py /path/to/shopbot/users.db

# Перезапустить
sudo systemctl restart shopbot
```

### Шаг 2: Подготовить 3x-ui панели
```bash
# Убедиться что панели доступны по HTTPS
# Добавить записи в таблицу xui_hosts:
INSERT INTO xui_hosts (host_name, host_url, connect_host, connect_port) 
VALUES ('NL-Amsterdam', 'https://nl.example.com:54321', 'nl.example.com', 443);
```

### Шаг 3: Собрать приложение
```bash
cd app
flutter pub get
flutter build apk --release  # для Android
```

### Шаг 4: Установить и тестировать
```bash
# Установить APK на телефон
adb install build/app/outputs/flutter-apk/app-release.apk

# Открыть приложение
# Зарегистрироваться
# Купить пробный тариф
# Подключиться к VPN
# Проверить интернет
```
